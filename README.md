# sso

Проект Signle-Sign-On сервиса на базе Keycloak

## Структура директорий

- `.helm` - чарты helm для разветывания компонентов SSO-серверов
- `keycloak` - конфигурации и файлы для сборки образа основного сервера Keycloak
- `themes` - собственные темы (для старта разработки полностью скопированы стоковые темы keycloak)

## Разработка тем

Для разработки тем нужно установить docker и docker compose plugin. Чтобы запустить keycloak в режиме разработки без кеширования тем, нужно поднять стек:
```shell
docker compose -f docker-compose-dev.yml up
```

После этого на порту `8080` будет доступен keycloak. При редактировании темы нужно просто обновить страничку в браузере и изменения вступят в силу.

Для создания новой темы, рекомендуется скопировать дефолтную тему (keycloak или base) и изменять ее.
