# sso

Проект Signle-Sign-On сервиса на базе Keycloak

## Структура директорий

- `.helm` - чарты helm для разветывания компонентов SSO-серверов
- `themes` - собственные темы (для старта разработки полностью скопированы стоковые темы keycloak)
- `controllers` - проекты контроллеров для kubernetes
- `extensions` - проекты расширения keycloak

## Сборка

Сборка данного проекта - это комплексный процесс. Он подразделяется на следующие этапы:
- `prebuild` - сборка всех расширений и библиотек.
- `cache` - кеширование в локальной директории всех артефактов расширений
- `build-docker` - сборка образов контейнеров
- `*-deploy` - развертывание проекта в нужной среде
