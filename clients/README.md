# Конфигурация клиентов

Данные проект содержит helm-чарт для создания и настройки всех необходимых клиентов.

## Процесс создания и конфигурации

Для создания, обновления клиента, необходимо создать/обновить ресурс sso.kacd.kz/v1beta1/Client на API-сервере Kubernetes. helm-чарт позволяет настроить реалмы, поместив их конфигурации в папку `.helm/templates`.

После всех редактирований, необходимо залить изменения в ветку dev и сделать `git push` ветки dev. Все изменения будут применены в кластер dev.
