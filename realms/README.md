# Конфигурация реалмов

Данные проект содержит helm-чарт для создания и настройки всех необходимых чартов с их доменными именами.

## Процесс создания и конфигурации

Для создания, обновления реалма, необходимо создать/обновить ресурс sso.kacd.kz/v1beta1/Realm на API-сервере Kubernetes. helm-чарт позволяет настроить реалмы, поместив их конфигурации в папку `.helm/templates` и создав дополнительный ресурс ingress.

После всех редактирований, необходимо залить изменения в ветку dev и сделать `git push` ветки dev. Все изменения будут применены в кластер dev.
