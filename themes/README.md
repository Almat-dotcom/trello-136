# Разработка тем

Для разработки необходимо на своем компьютере установить [Docker Desktop](https://docs.docker.com/desktop/install/windows-install/).

Если вы хотите создать новую тему, то в папке `themes` нужно создать новую папку с именем вашей темы, и внутри создать необходимые [типы тем](https://www.keycloak.org/docs/latest/server_development/#_themes). Далее необходимо запустить keycloak локально (см. далее) и в [Панеле администратора](http://localhost:8080/admin) для какого-то реалма изменить настройки темы под собственную.

> Рекомендуется за основу скопировать тему `default-themes/keycloak` и дорабатывать ее. Важно отметить, что некоторые стили, которые в исходной теме тянутся из node_modules не будут работать. Если нужны внешние библиотеки, то вы можете либо как статику прикрепить, либо как node_modules, но нужно сообщить об этом для внесения изменений в процесс сборки. 

Для запуска локального keycloak можно просто выполнить команду:
```shell
docker compose -f docker-compose-dev.yml up
```

При данном запуске любые изменения в директории themes будет сразу применятся.
